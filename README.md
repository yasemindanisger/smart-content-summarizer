# Smart Content Summarizer 

A modern, full-stack web application built with **Next.js (App Router)** and **Tailwind CSS** that leverages artificial intelligence to analyze, condense, and extract key insights from long articles, notes, and documents in seconds.

##  Features

- **AI-Powered Analysis:** Automatically processes text using advanced language models.
- **Multiple Output Formats:** 
  -  **Bullet Points:** Extracts key takeaways into concise bullet points.
  -  **Paragraph:** Condenses text into a well-structured fluid summary.
  -  **Keywords:** Pulls out top terms with brief explanations.
- **Modern UI/UX:** Sleek, responsive dark-mode interface built with Tailwind CSS and Lucide React icons.
- **Secure Architecture:** Backend API routes designed with Next.js Server Actions / API routes keeping API keys secure on the server side.

## Tech Stack

- **Frontend & Backend:** Next.js, React, Tailwind CSS
- **Icons:** Lucide React
- **AI Integration:** OpenAI API / Google Gemini API
- **Deployment:** Vercel
